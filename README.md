## ✨ Features

- **🌓 Dual Light/Dark Theme System**: Seamless client-side theme switching using `next-themes` and CSS custom variables.
- **🎨 Glassmorphism Aesthetic**: Rich visual hierarchy featuring frosted glass cards, dynamic glowing halos, gradient typography, and ambient background lighting.
- **💫 Fluid Micro-Animations**: Smooth scroll reveal, card elevation physics, and interactive hover states powered by `framer-motion`.
- **🛠️ Flagship Featured Projects**:
  - 🏖️ **SR Tour & Travels** — Interactive vacation booking web application with real-time search, dynamic category filters, and instant WhatsApp reservation routing ([Live Demo](https://srtourtravel.netlify.app/)).
  - 💳 **Session Subscription System** — Full-stack MERN client management and financial tracking system ([Live Demo](https://session-subscription-system-1.onrender.com)).
  - 🤖 **Before You Buy** — AI consumer decision engine powered by Playwright scraping & Google Gemini AI ([GitHub Repo](https://github.com/Sumit1075Raj/BeforeYouBuy)).
  - 🏡 **Ghar (House Price Predictor)** — Machine learning real estate valuation engine ([Live Demo](https://ghar-ai-powered-house-price-prediction--sumitraj1075.replit.app)).
  - 🌾 **Farm Saathi** — AI-powered livestock healthcare & disease diagnostic platform ([GitHub Repo](https://github.com/Sumit1075Raj/FarmSaathi---Livestock-Diagnostic-)).
- **📱 100% Mobile Responsive**: Perfectly tuned breakpoints for mobile (iPhone SE, Android), tablet, and desktop viewports.
- **⚡ SEO & Performance Optimized**: Pre-rendered static pages, Open Graph tags, fast Turbopack compilation, and crisp accessibility scores.

## 🚀 Getting Started

### Prerequisites
Make sure you have **Node.js (v18.0.0 or higher)** and **npm** installed on your system.

### 1. Clone the Repository
```bash
git clone https://github.com/Sumit1075Raj/portfolio.git
cd portfolio
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run the Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser to view the portfolio.

### 4. Build for Production
```bash
npm run build
```
